## Engineering philosophy

**Build for usefulness.** Solve a real problem, keep the experience intuitive, and make the product dependable.

**Design for maintainability.** Value clear architecture, readable code, testing, security, and documentation.

**Share what helps others.** Publish reusable tools and welcome constructive community feedback where projects are open for collaboration.

## Contributing

We appreciate bug reports, feature suggestions, documentation improvements, and code contributions to eligible open-source projects.

1. Find a project in our [repositories](https://github.com/orgs/substring-projects/repositories).

3. Open an issue to discuss a proposal, or submit a focused pull request.

Contribution and licensing rules are defined by each individual repository.
